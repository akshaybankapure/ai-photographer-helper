AI Photographer Helper

Analyze photos, get composition and lighting guidance, and manage shoot sessions through a simple REST API.

Browse endpoints OpenAPI YAML

Authentication

All requests require a Bearer token issued from the developer dashboard.

Header
Authorization: Bearer <your_api_token>

Base URL: https://api.aiphotographer.example/v1

Endpoints

Core routes for analysis, suggestions, presets, and sessions.

POST /analyze Analyze a photo

Upload or reference an image and receive quality scores, scene tags, and issue flags.

RequestJSON
// POST /v1/analyze
{
  "image_url": "https://cdn.example.com/portrait-01.jpg",
  "options": {
    "include_faces": true
  }
}
Response200
{
  "scores": {
    "overall": 82,
    "sharpness": 88,
    "exposure": 74
  },
  "scene_tags": ["portrait", "golden-hour"]
}
POST /suggest/composition Composition suggestions

Returns framing, rule-of-thirds, leading-line, and crop recommendations for a photo.

POST /suggest/lighting Lighting suggestions

Recommends exposure, white-balance, and lighting setup changes.

GET /presets List style presets

Optional query: ?category=portrait|landscape|night|product|street|all

POST /sessions Create a shoot session

Groups analyses and suggestions under a named shoot. Also supports GET, GET /{id}, and DELETE /{id}.

GET /sessions List shoot sessions

Paginated with limit (1–100, default 20) and optional cursor.

DELETE /sessions/{sessionId} Delete a session

Permanently removes the session and its linked analysis references. Returns 204.

Errors

    "request_id": "req_01HXYZ..."
